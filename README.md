# Uzski Corp Agent Skills

Reusable skills for coding agents.

## React to LiveView

Port React pages and components to Phoenix LiveView and HEEx while preserving styling, responsive behavior, and interactions. The skill discovers each project's conventions rather than assuming a particular framework, CSS system, or component library.

It covers source inspection, effective CSS, state and data mapping, Phoenix integration, accessibility, recovery states, and JavaScript lifecycle cleanup.

### Install

```sh
npx skills add Uzski-Corp/agent-skills --skill react-to-liveview-port
```

### Use

Ask your agent to use `react-to-liveview-port` to port a React page or component to your Phoenix application. Provide the source and destination paths and the requested scope.

[Read the skill](skills/react-to-liveview-port/SKILL.md).
